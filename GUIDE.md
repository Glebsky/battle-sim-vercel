# Краткое руководство: TSO Adventure Tactical Planner

## Главная концепция системы

> **Это НЕ обычный калькулятор на один лагерь.**  
> В стандартных симуляторах вы вручную подбираете генерала и войска под каждый отдельный лагерь.  
> **Этот проект — сквозной оптимизатор кампании:** вы отмечаете **все нужные лагеря** (сектор или всё приключение целиком), а планировщик берёт общий пул ваших генералов и автоматически распределяет их по всем лагерям, составляя готовый план атаки по волнам с минимальным числом заходов, учётом откатов (2 часа) и воскрешений (1-UP).

---

## 1. Где взять файл генералов?

1. Перейдите в симулятор на **[tsowiki.eu/simulator](https://tsowiki.eu/simulator/)**.
2. Откройте вкладку **«Генералы»** (где настроены ваши генералы и их таланты/навыки).
3. Нажмите кнопку **«Экспорт»** и сохраните файл `.json` (например, `tsowiki-generals.json`).
4. В нашем планировщике откройте вкладку **«Генералы»** и перетащите этот файл в область загрузки (файл автоматически сохранится в памяти браузера).

---

## 2. Быстрый запуск

```bash
npm start
# или: node planner/server.js
```
Откройте в браузере: **`http://localhost:8787`**

---

## 3. Порядок работы (4 простых шага)

1. **Генералы**:
   - Загрузите JSON с `tsowiki.eu/simulator`.
   - Отметьте галочками тех генералов, которых хотите отправить в бой.
2. **Лагеря**:
   - Выберите приключение из списка.
   - Кликните по лагерям на карте или используйте кнопки **«Сектор»** / **«Все»**.
3. **Войска**:
   - Выберите пресет доступных войск (**Элита** или **Все**).
   - В колонке **«Без потерь»** отметьте ценных юнитов (например, *Конные стрелки*, *Осадные войска*) — система гарантирует, что они пойдут только на безопасное 100% добивание и не погибнут.
4. **Параметры и Расчёт**:
   - Выберите режим:
     - **Максимум**: уничтожить максимум лагерей одновременно за одну волну (минимум времени на приключение).
     - **Беречь (Минимум)**: минимизировать потери генералов и войск.
   - Нажмите **«Рассчитать план волн»**.

---

## 4. Результат

Вы получите готовое расписание:
- **Волна 1, Волна 2, ...**: какие лагеря бьются параллельно.
- **Генерал и точный состав армии** под каждый лагерь.
- **Статусы генералов**: кто выжил, у кого сработал бесплатный слив (`1-UP`), а кто ушёл на откат 2 часа.
- Кнопка **«Копировать отчёт»** для отправки или сохранения тактики.
